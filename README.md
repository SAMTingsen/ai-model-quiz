# AI Model Quiz

A beginner-friendly quiz app for learning AI model concepts.

## Objective

Help non-technical users understand basic AI model and API concepts through a short interactive quiz.

## MVP Features

- Start the quiz
- Display 5 questions
- Show 4 answer options for each question
- Show whether the selected answer is correct
- Automatically proceed to the next question
- Display the final score and completion time
- Allow the user to restart the quiz

## Out of Scope

- User registration and login
- Database
- Leaderboard
- Admin dashboard
- Multiple quiz categories
- Social media sharing

## Target Users

Salespeople, product managers, and beginners who work with AI products but do not have a technical background.

## Success Criteria

- Users can complete the quiz without instructions
- The result and score are calculated correctly
- The application works on desktop and mobile
- The application is accessible through a public URL
